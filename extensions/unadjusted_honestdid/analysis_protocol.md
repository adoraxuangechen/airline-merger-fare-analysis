# Unadjusted event-study HonestDiD breakdown analysis

This extension fixes its estimand before calculating the breakdown value. It uses the unchanged 260-route, 6,235-observation panel and only route and quarter effects. The omitted event quarter is 2007Q4; eleven pre coefficients cover 2005Q1–2007Q3 and twelve later coefficients cover 2008Q1–2010Q4. The target is the equal-quarter mean for 2008Q4–2010Q4. The first three later coefficients have zero target weight, allowing anticipation/announcement effects from 2008Q1 while assuming no effect before then.

The pooled route-and-quarter model gives −5.58264%. That coefficient is a different contrast: it pools quarters before 2008Q4 rather than normalizing each later event coefficient to 2007Q4. The official relative-magnitude routine's l_vec acts on post-period effects and does not directly allow arbitrary pre-period weights as the target. This extension must therefore be called the **unadjusted event-study counterpart**. Its breakdown value must not be labeled the breakdown of the numerical pooled −5.58% coefficient.

The empirical breakdown value concerns the smallest nonnegative relative-magnitude M at which the official 95% C-LF confidence set accepts a zero target effect. M restricts consecutive-quarter changes in the untreated differential trend, including the reference-to-first-later-quarter transition; it does not bound the level of every post-period effect. The implementation first checks M = 0. If zero is already accepted there, the result is no positive robustness margin. Otherwise it brackets the first observed change from rejection to acceptance, checks a grid below that crossing, and refines M locally. Finite-grid resolution and any nonmonotonic acceptances are recorded; a numerical bracket is not asserted to prove a global continuous minimum between every sampled M.

Zero membership is evaluated by the official exported computeConditionalCS_DeltaRM function, with gridPoints = 1 and grid.lb = grid.ub = 0, returnLength = FALSE, hybrid_flag = LF, hybrid_kappa = 0.005, and alpha = 0.05. This directly evaluates the original test at zero; it is not inference from the closest point of a coarse full-confidence-set grid. Expected 'open endpoint' warnings on a one-point grid mean that the tested zero was accepted; they do not mean that an interval endpoint was estimated. Warnings are saved, and all other warnings cause the run to fail. A separate full-grid call will cross-check zero membership at the final bracket endpoints.

The full 23-by-23 covariance is route-clustered CR1 with the rank-based correction used by the main event estimator. The official HonestDiD package is version 0.2.8 at source commit 6813f02ed38f0b63bdca6915604b2eac90491303. Its source is unchanged. External seed argument 20260927 is passed consistently, but this commit's multi-post branch calls the internal least-favorable simulator without forwarding seed: the effective internal seed is 0 and the default simulation count is 1,000. The same detail applies to the existing adjusted analysis. A source and runtime audit is recorded separately.

Rebasing the descriptive event plot to 2008Q3 would change the numerical mean contrast. It would also treat announcement-period quarters differently in a sensitivity model, so a 2008Q3-based breakdown cannot be substituted without changing the no-anticipation setup. The current specification deliberately preserves the 2007Q4 reference used in the adjusted HonestDiD exercise.

## Follow-up pooled-associated target, September 27, 2026

The original protocol above describes the initial nine-quarter target. Following an independent projection-weight audit, the extension also evaluates the causal functional associated with the pooled regression under zero effects through 2007Q4. Its twelve post weights retain the three negative early-2008 entries and are not renormalized. The observed pooled coefficient decomposes into pre- and post-reference contributions; its numerical -5.58% is distinct from the post-only plug-in contrast. `pooled_target_metadata.json`, the sibling `pooled_weight_audit/` extension, and the final README give the exact identity and checks. Both targets are reported in `breakdown_summary.csv`, including their separate zero tests and full-grid validations. This addition records the follow-up sequence without rewriting the initial protocol as a prospective choice.
