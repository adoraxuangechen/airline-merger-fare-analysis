# Historical drafts and public archive scope

The current paper and replication entry point are in the [main README](../README.md). These archives preserve earlier papers, analysis results, and review snapshots. Historical findings and rebuild instructions may be superseded by the current pipeline.

Original PDFs and included historical source/result files are preserved byte-for-byte. Two historical document builders containing Chinese text and a duplicate Git-history bundle are retained in the private preservation copy and omitted from this English-only public tree. Their original paths, sizes, SHA-256 hashes, and reasons are recorded in [public archive omissions](../provenance/public_archive_omissions.json). No translation is presented as an original historical file.

The existing repository commit history remains intact, including [the pre-revision commit](https://github.com/adoraxuangechen/airline-merger-fare-analysis/tree/de38cd0e173d786c3d5c1edf9f463bb0dd4049f5). Omission from this release tree does not rewrite history. The omitted v1 document builder can be inspected at that historical commit. Current document builds use the maintained builders under `documents/`.

The [public archive manifest](../provenance/archive_sha256_manifest.json) covers files actually included here and the named archival records. The separate private-capture manifest records the earlier complete local capture, including omitted files; it is not a claim that every captured file appears in this public tree. The Git-history README has been updated for this public release; its original hash is recorded alongside the omissions. All other included archival files remain unchanged.
